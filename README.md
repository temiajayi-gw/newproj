## New Project Command
This creates a new repository with things I personally like including in a javascript / typescript project.

### Things I like in a project
- pnpm as a package manager
- git initialized
- biomejs, vitest, typescript, tsx and lefthook as base developer dependencies
- gitignore, README, lefthook and tsconfig already setup

## How to use
- Clone this repository.
- Set an alias in bash.
```bash
alias newproj="bash path/to/repository/newProject.sh
```
- Then generate your new project, adding a directory name as your argument. In this case I used `my-app`
```bash
newproj my-app
```
This has now been extended to include python and go

Have fun!
